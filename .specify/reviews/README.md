# Code Review Reports

Numbered reports generated by the `review` skill.

## Conventions

| Item | Rule |
| ---- | ---- |
| Folder | `.specify/reviews/` |
| Name | `{NNN}_{slug}.md` (e.g., `001_feature_transactions.md`) |
| Numbering | `001`, `002`, … — next = `max(NNN) + 1` |
| Active Reference | `.specify/review_ref.json` points to the most recently generated report |
| Template | `.specify/templates/review-template.md` |

## `review_ref.json`

```json
{
  "name": "001_feature_transactions",
  "path": ".specify/reviews/001_feature_transactions.md",
  "updatedAt": "2026-07-19"
}
```

| Field | Description |
| ----- | ----------- |
| `name` | File name without extension |
| `path` | Path relative to the repository root |
| `updatedAt` | ISO Date (`YYYY-MM-DD`) |

## Related Skills

| Skill | Role |
| ----- | ---- |
| `review` | Generates automated reports identifying issues, technical debt, and ambiguities without altering the source code. |

## Rules

- **Read-Only**: The review process itself must never modify the source code, serving solely to generate metrics and pointers in the report.
- Use real paths under `src/` and `src/tests/`.
- Findings tables are limited to 50 rows to save tokens.
- Mandatory footer in each report: `<!-- created: YYYY-MM-DD | modified: YYYY-MM-DD -->`.
